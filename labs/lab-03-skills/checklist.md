# Lab 3 - Done when

- [ ] The Robot Framework Agent Skills are installed inside the repository, and your agent can name them.
- [ ] `results/lab-03/with-skills.robot` exists.
- [ ] Your skill's folder sits in your agent's skill folder, and its `name` matches the folder's name.
- [ ] Its `description` says what it checks and when to use it.
- [ ] Its rule, reason and examples are those of your convention, and the template's comment is gone.
- [ ] A review prompt about test conventions loads your skill.
- [ ] A prompt about something unrelated does not load it.
